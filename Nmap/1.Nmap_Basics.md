
# 🔐 Nmap Port Scanning Cheat Sheet


## 🎯 Specifying Ports

- **Scan specific ports**  
  `-p22,80,443`  
  Scans ports 22, 80, and 443.

- **Scan a range of ports**  
  `-p1-1023`  
  Scans ports from 1 to 1023 inclusive.  
  `-p20-25`  
  Scans ports 20 through 25.

- **Scan all ports**  
  `-p-`  
  Scans all 65535 ports.

- **Scan top ports**
  - `-F` — Scans top 100 most common ports.
  - `--top-ports 10` — Scans top 10 most common ports.

## ⏱️ Scan Timing (`-T` option)

| Level     | Value | Description |
|-----------|-------|-------------|
| Paranoid  | `-T0` | Slowest, 5 min delay between probes |
| Sneaky    | `-T1` | Stealthy, slower |
| Polite    | `-T2` | Slower than default |
| Normal    | `-T3` | Default |
| Aggressive| `-T4` | Fast, common in CTFs |
| Insane    | `-T5` | Fastest, might miss open ports |

> ⚠️ Use `-T0` or `-T1` to avoid IDS alerts in real-world engagements.  
> `-T4` is great for CTFs, `-T5` can cause inaccuracies.

## 📶 Controlling Packet Rate

- **Minimum rate**:  
  `--min-rate <number>`  
  Example: `--min-rate 15` → At least 15 packets/sec

- **Maximum rate**:  
  `--max-rate <number>`  
  Example: `--max-rate 10` → No more than 10 packets/sec

## 🔄 Parallelization (Probing)

- **Minimum parallelism**  
  `--min-parallelism <number>`  
  Example: `--min-parallelism 512` → Minimum 512 probes in parallel

- **Maximum parallelism**  
  `--max-parallelism <number>`  
  (same format as above)

## 🔍 Port Scan Types

| Scan Type       | Command                          | Notes |
|-----------------|----------------------------------|-------|
| TCP Connect     | `nmap -sT <target>`              | Full TCP handshake |
| TCP SYN (Stealth)| `sudo nmap -sS <target>`        | Half-open scan |
| UDP Scan        | `sudo nmap -sU <target>`         | Slower, useful for UDP services |

## 🧰 Common Options Summary

| Option                  | Description                 |
| ----------------------- | --------------------------- |
| `-p-`                   | Scan all ports              |
| `-p1-1023`              | Scan ports 1 to 1023        |
| `-F`                    | Scan top 100 ports          |
| `-r`                    | Scan ports in order         |
| `-T<0-5>`               | Timing template             |
| `--max-rate 50`         | Limit to 50 packets/sec     |
| `--min-rate 15`         | At least 15 packets/sec     |
| `--min-parallelism 100` | At least 100 probes at once |
