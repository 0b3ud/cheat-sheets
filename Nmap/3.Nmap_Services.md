# 🛠️ Nmap Service Detection & Output Cheat Sheet

## 🔍 Detecting Services and OS

| Option                        | Meaning |
|-------------------------------|---------|
| `-sV`                         | Determine service/version info on open ports |
| `-sV --version-light`         | Use the most likely probes (faster scan) |
| `-sV --version-all`           | Use all available probes (more thorough) |
| `-O`                          | Detect OS of target host |
| `--traceroute`                | Run traceroute to discover network path |
| `-A`                          | Aggressive scan: enables `-sV`, `-O`, `-sC`, and `--traceroute` |

---

## 🔎 Nmap Scripts

| Option                       | Meaning |
|------------------------------|---------|
| `--script=SCRIPTS`           | Run specific Nmap scripts |
| `-sC` or `--script=default`  | Run default scripts (recommended for quick scans) |

---

## 💾 Saving Scan Output

| Option   | Format & Purpose |
|----------|------------------|
| `-oN`    | Save output in **Normal** human-readable format |
| `-oG`    | Save output in **Grepable** format (for scripts/pipelines) |
| `-oX`    | Save output in **XML** format (for automation/parsing) |
| `-oA`    | Save output in **All** formats (`-oN`, `-oG`, and `-oX`) |

---

🧠 **Pro Tips**:
- Use `-A` when doing quick recon and want a bit of everything.
- Pair `--script` with discovery scripts like `http-enum`, `ftp-anon`, etc., for better penetration testing insights.
- Save scans with `-oA` to avoid re-scanning later.
