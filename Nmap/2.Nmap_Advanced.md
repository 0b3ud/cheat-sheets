
# 🚀 Advanced Nmap Cheat Sheet 

## 🔎 Advanced TCP Scan Types

| Scan Type                      | Example Command                                         | Description                             | Server Response                                                        |
| ------------------------------ | ------------------------------------------------------- | --------------------------------------- | ---------------------------------------------------------------------- |
| TCP Null Scan<br>Hide from IDS | `sudo nmap -sN 10.10.218.54`                            | No flags set; closed ports respond      | Closed ports respond with **RST**, open ports **no response**          |
| TCP FIN Scan                   | `sudo nmap -sF 10.10.218.54`                            | Sends FIN flag; closed ports respond    | Closed ports respond with **RST**, open ports **no response**          |
| TCP Xmas Scan                  | `sudo nmap -sX 10.10.218.54`                            | Sets FIN, URG, and PSH flags            | Closed ports respond with **RST**, open ports **no response**          |
| TCP Maimon Scan                | `sudo nmap -sM 10.10.218.54`                            | Used against firewalls and filters      | Varies: sometimes **no response** from open ports, **RST** from closed |
| TCP ACK Scan                   | `sudo nmap -sA 10.10.218.54`                            | Map firewall rules, not port states     | **RST** indicates unfiltered, no response = filtered                   |
| TCP Window Scan                | `sudo nmap -sW 10.10.218.54`                            | Uses TCP window size to find open ports | Like ACK, but checks window size to infer open vs closed               |
| Custom TCP Scan                | `sudo nmap --scanflags URGACKPSHRSTSYNFIN 10.10.218.54` | Custom flags for advanced scanning      | Depends on flag combo; **RST** or no response varies by state          |


> 🧠 These scan types manipulate TCP flags to trigger replies and detect filtered/open/closed ports in stealthy ways.

## 🕵️ Stealth & Obfuscation Techniques

| Technique           | Example Command                        | Description                                      |
| ------------------- | -------------------------------------- | ------------------------------------------------ |
| Spoofed Source IP   | `sudo nmap -S SPOOFED_IP 10.10.218.54` | Disguise your IP                                 |
| Spoofed MAC Address | `--spoof-mac SPOOFED_MAC`              | Fake your MAC address                            |
| Decoy Scan          | `nmap -D DECOY_IP,ME 10.10.218.54`     | Blend in with decoys                             |
| Idle (Zombie) Scan  | `sudo nmap -sI ZOMBIE_IP 10.10.218.54` | Use idle host to avoid detection (use a printer) |

## 🧬 Packet Fragmentation (IDS evasion)

| Option  | Description |
|---------|-------------|
| `-f`    | Fragment packets into 8 bytes |
| `-ff`   | More fragmentation, typically 16 bytes |

---

## ⚙️ Misc Options

| Option                     | Purpose |
|----------------------------|---------|
| `--source-port PORT_NUM`   | Set specific source port |
| `--data-length NUM`        | Append random data to reach given length |
| `--reason`                 | Show reason behind scan result |
| `-v`                       | Verbose output |
| `-vv`                      | Very verbose |
| `-d`                       | Enable debugging |
| `-dd`                      | Extra debugging info |

---

🧠 **Tips**:  
- Use stealth scans (e.g. Xmas, Null, FIN) to evade firewalls and detection systems.
- Combine `-f`, spoofing, and decoys for better obfuscation.
- Always review legality before using these techniques outside controlled environments.
