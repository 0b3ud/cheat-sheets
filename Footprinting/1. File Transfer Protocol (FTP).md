## 📌 Overview

**FTP (File Transfer Protocol)** is a standard network protocol used to transfer files between a client and a server on a computer network. It was developed in the early 1970s and remains widely used, especially in legacy systems. Due to its simplicity and frequent misconfigurations, FTP is a common target during the reconnaissance phase of a penetration test.

## 🔍 Footprinting FTP

Footprinting involves collecting information about systems and services before launching an actual attack. When footprinting FTP, the goal is to discover misconfigurations, vulnerabilities, or access controls that could be exploited.

## 📦 FTP Service Information

| Parameter         | Value                        |
|------------------|------------------------------|
| Protocol         | FTP (File Transfer Protocol) |
| Default Port(s)  | 21 (Control), 20 (Data - Active mode) |
| Protocol Type    | TCP                          |
| Authentication   | Username/password (can allow anonymous access) |
| Encryption       | None (FTP), optional with FTPS or SFTP |

---

## 🔄 FTP Modes

### 1. **Active Mode**
- The client opens a random port and sends the port number to the server via the control channel.
- The server initiates a data connection back to the client’s specified port.
- Can be blocked by firewalls due to incoming connections.

### 2. **Passive Mode**
- The server opens a random port and tells the client where to connect.
- The client initiates both the control and data connections.
- More firewall-friendly and common in modern implementations.

## 🧰 Reconnaissance Techniques

### 1. **Port Scanning**
Use tools like `nmap` to identify if port 21 is open and running FTP:
```bash
nmap -p 21 -sV <target-ip>
```
### 2. **Banner Grabbing**
Retrieve the FTP server version and OS for fingerprinting:
```shell
telnet <target-ip> 21
```
### 3. **Anonymous Login Check**
Test if anonymous login is enabled:
```bash
ftp <target-ip>
# Use username: anonymous and any password
```
### 4. **Brute-Force Attacks**
```bash
hydra -l admin -P passwords.txt ftp://<target-ip>
```
### 5. **Service Enumeration**
Use tools like `nmap` with NSE scripts for deeper FTP analysis:
```bash
nmap -p 21 --script=ftp-anon,ftp-bounce,ftp-syst,ftp-vsftpd-backdoor <target-ip>
```

## 🛡️ Common Misconfigurations

- Anonymous access enabled
- Default or weak credentials
- Directory traversal vulnerabilities
- Unencrypted communications (no FTPS/SFTP)
- World-writable directories
