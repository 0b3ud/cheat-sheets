## 📌 Overview

**SMB (Server Message Block)** is a network protocol used for providing shared access to files, printers, and serial ports between nodes on a network. It operates over TCP and is commonly found in Windows environments. SMB is a high-value target during penetration testing due to its historical vulnerabilities and widespread usage.

---
## 📦 SMB Service Information

| Parameter       | Value                                                   |
| --------------- | ------------------------------------------------------- |
| Protocol        | SMB (Server Message Block)                              |
| Common Versions | SMBv1 (insecure), SMBv2, SMBv3 (secure with encryption) |
| Default Port(s) | TCP 445 (Direct SMB), TCP 139 (NetBIOS/legacy)          |
| Protocol Type   | TCP                                                     |
| Authentication  | Username/password, NTLM, Kerberos                       |
| Encryption      | SMBv3 supports encryption (SMBv1 and v2 do not)         |

---
## 🔍 Footprinting SMB

Footprinting SMB involves identifying open SMB services, shared folders, permissions, user accounts, and potential misconfigurations. This information is crucial for lateral movement and privilege escalation in internal networks.

---
## 🧰 Reconnaissance Techniques

### 1. Port Scanning

Use `nmap` to detect open SMB ports:
```bash
nmap -p 139,445 -sV <target-ip>
```
### 2. SMB Version Detection
Use `nmap` NSE script to detect SMB version:
```bash
nmap --script=smb-protocols -p445 <target-ip>
```
### 3. Enumerate Shares
Check for shared folders with `smbclient`:
```bash
smbclient -L //<target-ip> -N
```
### 4. User and Host Enumeration
Use `enum4linux` to gather information:
```bash
enum4linux -U <target-ip>
enum4linux -a <target-ip>
```
### 5. Brute-Force Authentication
Use `hydra` for brute-force attacks:
```bash
hydra -L users.txt -P passwords.txt smb://<target-ip>
```
### 6. Access a Share
Connect to a discovered share:
```bash
smbclient //<target-ip>/sharename -U username
```
## 🛡️ Common Misconfigurations

- Null session enabled (unauthenticated access to shares)
- Weak or default passwords
- Excessive permissions on shared folders
- SMBv1 enabled (subject to EternalBlue and other exploits)
- Guest access allowed
- Information disclosure via SMB banners
